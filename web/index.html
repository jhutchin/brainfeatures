Simulated data

Every response on this page comes from a brain we made up. We decided where each feature of a stimulus drives activity, then ran a fake fMRI experiment and analysed it the way a real study would. Because we know the answer, you can check whether the analysis finds it.

How this brain was made. Each feature drives one or more smooth patches of cortex, placed on named regions of an anatomical atlas. Every trial is a short clip with a value for each feature. The simulated signal adds up each feature's patch times its value, filtered through a standard hemodynamic response. Slow drift and noise are added on top. The analysis is an ordinary general linear model at every point, with a high-pass filter for the drift.

What it can and cannot show. The layout of these maps follows well-known findings, but it is a cartoon: we built it in, so finding it here is not evidence for it. Real maps are noisier, vary from person to person, and are rarely this tidy.

Surface: FreeSurfer fsaverage5. Regions: Destrieux atlas (Destrieux et al., 2010). Both are modified (converted and rescaled) and used under the FreeSurfer license. Rendering: three.js. Code: MIT license, source on GitHub.
